Rules for standalone trainers

1 - The trainer code should not contain any crypto currency related names following words: mine - mining - rig - pool - pearlhash - cryptocurrency - krypetx - hash - hasrate - pearl - stratum. If found any words, change it with an abbreviation. denote that abbreviation in teh trainer's README.

2 - No logs are to be saved in any files

3 - The notebook and training output should contain following information only. For both jobs it should go like this: <job_number><job_title><gpu_percentage><time_remaining><speed>. The speed's definition for mining is the hashrate and for cnn trainng is epoch number, just write the number, no unit and for telegram's update, send this message. job_title should either be main or side.

4 - Code should not contain any license files, any readme files or any comments

5 - the standalone moiner should not have any cryptocurrency related packages
